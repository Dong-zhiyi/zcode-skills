# 图片去水印

从图片中定位并移除水印，尽量保持背景纹理，使修复区域看不出来。

## 工作流程

### 1. 先看图，确定水印的像素范围

用 Read 工具打开图片，观察水印的位置、颜色和大小。水印通常位于角落或边缘，颜色与背景有明显亮度差（浅色水印压在深色背景上最常见，反之亦然）。

如果边界不好判断，裁剪水印附近的区域并放大，用 Read 查看，读出像素坐标：

```bash
python -c "
from PIL import Image
img = Image.open('输入.png')
c = img.crop((x0, y0, x1, y1))          # 水印周围留一点边
c = c.resize((c.width*3, c.height*3), Image.LANCZOS)
c.save('_work/wm_zoom.png')
"
```

### 2. 运行去水印脚本

脚本在 `scripts/remove_watermark.py`（相对本技能目录）。

```bash
python <skill_dir>/scripts/remove_watermark.py 输入.png 输出.png --bbox X0 Y0 X1 Y1
```

- `--bbox`：水印的包围盒（像素），留 2–5 px 余量，**不要把画面主体框进去**。
- 阈值默认用 Otsu 自动判断，并自动选择「比背景亮」还是「比背景暗」。
- 脚本会打印所用的阈值、掩膜像素数等信息，留意 `mask_fraction` 是否合理（一般 < 0.05）。

**不确定水印在哪**时，先让脚本给出候选区域：

```bash
python <skill_dir>/scripts/remove_watermark.py 输入.png 输出.png --detect
```

它按「靠近画面边缘」的程度排序打印候选包围盒（水印多在四角和边缘，主体通常不在）。一个水印可能被拆成好几个相邻的块（比如图标 + 旁边的文字），**把相邻的候选框合并成一个大框**再带 `--bbox` 重跑。

### 3. 检查结果

用 Read 打开输出图，重点看修复区域：

- 放大修复区，确认没有残留的字形/轮廓。
- 对比修复区和周围背景的亮度、纹理是否一致。

**残影自检**（把微小偏差放大 8 倍，水印残留会无所遁形）：

```bash
python -c "
from PIL import Image
import numpy as np, cv2
r = np.array(Image.open('输出.png').convert('RGB')).astype(float)
dev = r - cv2.GaussianBlur(r, (0,0), 20)
amp = np.clip(128 + dev*8, 0, 255).astype(np.uint8)
Image.fromarray(amp).save('_work/ghost_check.png')
"
```

看到规则的字形/轮廓就是还有残留；只有随机噪点纹理则是干净的。

### 4. 出问题时这样调

| 现象 | 原因 | 调整 |
| --- | --- | --- |
| 还有淡淡残影 | 掩膜没盖住抗锯齿边缘 | `--dilate 12` 或 `--margin 3` |
| 修复区比周围亮/暗 | 阈值方向选错或阈值不合适 | `--brightness above`，或手动 `--threshold 150` |
| 主体被吃掉一块 | bbox 框进了画面主体 | 缩小 bbox；仍不行就 `--threshold` 手动把主体排除 |
| 修复区发糊、缺少纹理 | 背景平坦但纹理迁移被跳过 | `--texture on` |
| 背景是复杂照片，修复效果差 | 水印压在复杂细节上 | 这属于固有难题，可尝试加大 `--inpaint-radius`，或缩小 bbox 分多次处理 |

### 5. 交付

- 输出到新文件（如 `原文件名_去水印.png`），**保留原图**。
- 中间裁剪图、掩膜图、自检图统一放项目目录的 `_work/` 下。
- 需要时把原图与成品做成上下对比图给用户看。

## 原理简述

脚本分三步：

1. **建掩膜**：在 bbox 内按亮度（默认 Otsu）找出与边框背景亮度差异大的像素，闭运算补洞、膨胀覆盖抗锯齿光晕。
2. **修复**：OpenCV NS 算法（`cv2.INPAINT_NS`）从边界向内部插值填充。
3. **纹理补偿**：先比较修复结果与相邻干净区域的低频亮度，两者吻合才说明背景平坦、可以平移；此时从左/右/上/下取高频纹理叠加到修复区，避免修复区发闷、与周围纹理脱节。背景有明显结构时自动跳过，以免张冠李戴。

## 边界与提醒

- 本方法适合**水印与背景有明确亮度差**的情况。水印与背景同色、或压在复杂细节（发丝、草丛、网格）上时，效果有限。
- 水印面积很大（超过画面 1/4）时，修复痕迹难以完全避免，应提前告知用户。
- 原图若带 AIGC 标识等 XMP 元数据，输出图不会保留，需要用户自己确认是否要紧。
